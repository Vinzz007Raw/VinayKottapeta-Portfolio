01 · Problem

The problem

Every weekend in Hyderabad, someone's friend cancels at the last minute, and somewhere else someone skips a movie because they don't want to go alone. Today those seats get swapped in random WhatsApp groups with no way to know who's real.

Extra tickets go wastePeople buy tickets for friends who cancel last minute
Watching aloneMany want company but don't know anyone going to the same show
WhatsApp chaosCurrent sharing happens in random groups — no trust or verification
Fake tickets riskNo safe way to verify tickets before meeting
02 · Solution

Our solution: FlixBuddy

A safe, social-first platform to find movie companions and share seats in Hyderabad. FlixBuddy puts companions first and resale second.

01

Post Your Seats. Share extra tickets or invite people to join your booking.

02

Browse & Discover. Find listings by movie, theater, time, or price in Hyderabad.

03

Connect Safely. Real-time in-app chat. See verified ticket proof before meeting.

04

Watch Together. Split cost, enjoy the movie with new friends or old ones.

03 · How It Works

04 · UI Screens

Four core screens

The concept-to-UI walkthrough is built around four mobile-first screens — discovery, filtered browsing, seat posting, and listing-plus-chat.

UI Screen 1: Home / Discovery

First screen users see — welcoming, fast access to trending movies & actions. This screen drives discovery and posting.

Key elements

  • 01Clean navbar with location (Hyderabad)
  • 02Powerful search bar
  • 03Big primary CTA: 'Post your seats'
  • 04Trending movies section (Telugu focus)
  • 05Easy 'View Seats' on movie cards

UI Screen 2: Browse & Discover

Find companions or tickets quickly with smart filters. Users can instantly see trusted, verified listings.

Key elements

  • 01Horizontal filter chips (Movie, Date, Theater, Price, Verified)
  • 02Clean listing cards with movie poster thumbnail, theater & show time, seats available, price / type badge, and sharer rating
  • 03Big 'I'm interested' CTA

UI Screen 3: Post Your Seats

Simple, guided form to share seats or find companions. Designed to be fast and trustworthy.

Key elements

  • 01Movie search with suggestions
  • 02Hyderabad theater dropdown
  • 03Date + Time pickers
  • 04Listing Type selector (highlighted 'Companions wanted')
  • 05Number of seats + optional price
  • 06Description box
  • 07Ticket proof upload (for verification)
  • 08Clear 'Preview & Post' button

UI Screen 4: Listing Detail & Chat

Build trust before meeting — full info + real-time chat. Safety first: chat happens inside the app. Users see proof before sharing numbers.

Key elements

  • 01Large movie poster + full details
  • 02Sharer profile with rating
  • 03Ticket proof thumbnail (tap to view)
  • 04Big 'I'm interested - Start chat' CTA
  • 05Real-time chat preview

06 · Features & Safety

Key features & safety first

Six product features designed so strangers can become movie buddies safely — companions first, resale second.

Verified ListingsUsers upload ticket proof. We review & badge trusted listings.
Real-time ChatBuilt-in messaging. No phone numbers shared until both are ready.
Hyderabad FocusPre-loaded popular theaters (PVR, INOX, etc.) + local movies.
Social by DesignPrimary mode is 'find companions'. Resale is secondary option.
Ratings & ReviewsAfter every meet-up, users can rate each other for future trust.
Safety ToolsReport button, block user, clear disclaimers on every screen.
07 · Tech & Roadmap

Tech stack & roadmap

This work is concept-to-UI. The stack and roadmap below are planned — they describe a recommended path to a Hyderabad MVP, not a product that has already been built.

Recommended tech stack (planned)

Planned Frontend: Next.js 16 + Tailwind + shadcn/ui Backend: Supabase (Auth, DB, Storage, Realtime) Hosting: Vercel (free tier) Payments (Phase 2): Razorpay Search: Supabase full-text (upgrade later)

Development roadmap (planned)

  • 01Phase 1 (4–6 weeks): Core UI + Auth + Listings + Chat
  • 02Phase 2: Verification flow + Ratings + Razorpay
  • 03Phase 3: Push notifications + PWA + Multi-city
  • 04Phase 4: Admin tools + Scale

MVP goal (planned): launch in Hyderabad with 50+ active listings.
